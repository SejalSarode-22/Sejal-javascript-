About This Project

This Live Character Counter is a simple web application designed to count characters in real-time while typing.

It helps users track their input length, especially useful for forms, social media posts, and text limits.

This project is built using HTML, CSS, and JavaScript with a focus on clean UI, validation, and interactive design.

Developed as a mini project to demonstrate front-end skills and user interface design.
